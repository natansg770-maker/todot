# תודות צוות — קעמפ גן ישראל משפחת השלוחים הצעירים

מערכת לתיאום תודות של הצוות הבכיר לצוות הקעמפ: מי מתקשר למי, עדכון אחרי שיחה/סמס, משוב, והמלצה אם עוד מישהו צריך להודות.

## הרצה

```bash
npm install
npm run dev
```

פתחו את [http://localhost:3000](http://localhost:3000).

לייצור:

```bash
npm run build
npm start
```

הנתונים נשמרים בקובץ `data/db.json` בשרת. חשוב להריץ על שרת עם דיסק קבוע (לא serverless ללא אחסון), כדי שכל הצוות הבכיר יראה את אותם עדכונים.

## מה אפשר לעשות

- כניסה כאיש צוות בכיר
- צפייה במשימות התודה שלי ועדכון אחרי שיחה/סמס
- סקירת התקדמות כללית
- מדריך צוות לפי תפקידים
- ניהול: הוספת תפקידים ואנשים, שיוך ידני, חלוקה אוטומטית
